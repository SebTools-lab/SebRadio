## SebRadio 3.6

**PL**
- Pasek tytułu okna pokazuje nazwę stacji taką jak karta „Teraz gra” (zapisana nazwa stacji ma pierwszeństwo)
- Nazwa stacji wysyłana przez serwer, będąca samym identyfikatorem (np. 632cb48f613bac0856b931ab), jest pomijana

**EN**
- The window title shows the same station name as the "Now playing" card (saved station name first)
- A server-provided station name that is just an ID (e.g. 632cb48f613bac0856b931ab) is ignored

The executables are signed with a self-signed certificate, so Windows SmartScreen may show a warning.
