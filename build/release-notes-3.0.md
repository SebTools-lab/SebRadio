## SebRadio 3.0

**PL** - Pierwsze wydanie. Pobierz `SebRadio-Setup.exe` i uruchom (bez uprawnień administratora).
- Odtwarzanie MP3, AAC/AAC+, HLS (.m3u8), playlist .pls/.m3u (silnik BASS - pobierany przez instalator)
- Informacje o strumieniu, czas startu, pamięć ostatniego linku i głośności
- Rozpoznawanie utworów (Shazam): wykonawca i tytuł, kopiowanie, wyszukiwanie w YouTube i Apple Music
- Instalator i program PL/EN, deinstalator, tryb cichy `-Silent [-Target <folder>] [-Lang pl|en]`

**EN** - First release. Download `SebRadio-Setup.exe` and run it (no admin rights needed).
- Plays MP3, AAC/AAC+, HLS (.m3u8), .pls/.m3u playlists (BASS engine - downloaded by the installer)
- Stream info, start time, remembers last link and volume
- Song recognition (Shazam): artist and title, copy buttons, YouTube and Apple Music search
- PL/EN installer and app, uninstaller, silent mode `-Silent [-Target <folder>] [-Lang pl|en]`

The executables are signed with a self-signed certificate, so Windows SmartScreen may show a warning.
