## SebRadio 3.2

**PL**
- Historia utworów: rozpoznane przez Shazam i podawane przez stację tytuły zapisują się automatycznie z datą, stacją i linkami (YouTube, Apple Music, Shazam); okno Historia z wyszukiwaniem, kopiowaniem i usuwaniem; plik `%AppData%\SebRadio\historia.csv` otwiera się w Excelu
- Zapisane stacje: lista „Moje stacje” w oknie, przycisk Zapisz, okno Stacje (graj, zmień nazwę, usuń, kolejność)
- Plik `%AppData%\SebRadio\stacje.txt` (`Nazwa = link`) – można dopisać wiele stacji naraz, program wczytuje zmiany sam
- Import stacji z plików .m3u / .m3u8 / .pls / .txt
- Wyszukiwarka stacji w otwartej bazie radio-browser.info (nazwa, kraj), odsłuch i zapis jednym klikiem
- Zapisane stacje w menu ikony w zasobniku i pod prawym przyciskiem w mini odtwarzaczu
- Automatyczne wznawianie po zerwaniu połączenia (do włączenia/wyłączenia w Ustawieniach)
- Wyłącznik czasowy (15–120 min) z wyciszaniem na końcu, także w menu zasobnika
- Osobne okno Ustawienia (X do zasobnika, wznawianie, język)

**EN**
- Song history: songs recognized by Shazam and titles sent by the station are saved automatically with date, station and links (YouTube, Apple Music, Shazam); History window with search, copy and delete; the file `%AppData%\SebRadio\historia.csv` opens in Excel
- Saved stations: "My stations" list in the window, Save button, Stations window (play, rename, delete, reorder)
- File `%AppData%\SebRadio\stacje.txt` (`Name = link`) – add many stations at once, changes are picked up automatically
- Import stations from .m3u / .m3u8 / .pls / .txt files
- Station search in the open radio-browser.info database (name, country), listen and save with one click
- Saved stations in the tray icon menu and in the mini player's right-click menu
- Automatic reconnect when the connection drops (toggle in Settings)
- Sleep timer (15–120 min) with fade-out, also in the tray menu
- Separate Settings window (X to tray, reconnect, language)

The executables are signed with a self-signed certificate, so Windows SmartScreen may show a warning.
